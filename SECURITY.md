# Política de segurança

Relate vulnerabilidades para **security@nimbai.app** (ou via GitHub Security Advisories). Resposta inicial em até 72 h.

- Versões suportadas: a última release minor.
- Segredos: nunca no repositório; produção em Cloudflare Workers Secrets; `.env.example` contém só nomes.
- Rotação: trimestral e imediata em suspeita de vazamento.
- Dados pessoais: ver política de privacidade em nimbai.app/privacidade.
